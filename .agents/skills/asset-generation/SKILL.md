# Asset Generation Skill

## Purpose
Generates high-resolution vector and graphic assets supporting UI concepts and digital product cards.

## Asset Directives
1. **SVG & Vector Fidelity:** Use clean SVG markup for technical diagrams, architecture flowcharts, and product thumbnails.
2. **High-Tech Aesthetic:** Schematics, terminal interfaces, micro-grids, and minimalist developer badges.
3. **Optimized Delivery:** Inlined SVGs or modern WebP/AVIF images with explicit width and height to prevent CLS.
