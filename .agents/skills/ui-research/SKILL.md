# UI Research Skill

## Purpose
Establishes modern web standards, headless component best practices, elite typography pairings, and crisp light theme design tokens.

## Design Token Standards
* **Light Canvas:** `#FFFFFF` or `#FAFAFA`
* **Card & Elevated Surfaces:** `#FFFFFF` with hairline `1px` border (`#E2E8F0` or `#E4E4E7`)
* **Text Contrast:** Base text $\ge 4.5:1$ against background
* **Accents:** Emerald (`#059669`), Amber (`#D97706`), Cobalt (`#2563EB`)
* **Typography:** Geist Sans + Geist Mono (default), Inter + JetBrains Mono, Plus Jakarta Sans + Geist Mono
