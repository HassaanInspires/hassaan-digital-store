2. **Framework & Runtime:** Next.js 15+ (App Router) with full Metadata API (dynamic OpenGraph, SEO, Twitter cards, sitemap.xml, robots.txt).
3. **Database & Infrastructure:** Supabase PostgreSQL with strict migration tracking in `supabase/migrations/`.
4. **Payments & Webhooks:** Lemon Squeezy integration enforced by zero-trust HMAC SHA-256 webhook signature verification.
5. **Asset Security:** Zero-trust asset delivery via private Supabase Storage buckets, 60-second signed URLs, and PDF social DRM watermarking with `pdf-lib`.
